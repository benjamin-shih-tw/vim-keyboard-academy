# Vim Keyboard Academy

用 GitHub Dark 風格的 Vim UI，逐鍵學會純鍵盤編輯、C++ 競賽流程、CPH Modern 與 Competitive Companion。

**線上教學：** https://benjamin-shih-tw.github.io/vim-keyboard-academy/

## 內容

- 46 個互動課程、158 個 Vim／CPH 操作
- 播放、暫停、重播、逐課切換與 0.5×–2× 速度
- 直接鍵盤輸入的練習模式
- 課程搜尋、章節篩選與本機進度保存
- SF Mono、`#1A1A1A`、GitHub Dark C++ 染色
- CPH Modern Judge、templates 與 Competitive Companion 匯入動畫
- 桌面與手機版面
